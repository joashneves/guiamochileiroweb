

# Comandos dockers

## help
Não existe um `docker help`, mas ao colocar somente `docker` ele mostra um lista muito útil de comandos, e caso precisar entender um comando você pode usar `docker [commando] --help` para conseguir mais detalhes do comando em especifico.

## version
Mostra a versão que esta rodando o docker, com `docker version` pode ser usado para verificar se esta tudo funcionando como deveria.

## pull
Para buscar uma imagem no [Docker Hub](https://hub.docker.com/) escreva `docker pull [nome da imagem]` como pro exemplo
```bash
docker pull hello-world
```
